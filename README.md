# PORTOFOLIO

### Website ini adalah portofolio pribadi Febiola Safira, dibuat untuk memenuhi tugas slicing web. Tampilan website terinspirasi dari portofolio kak Altamis Atmaja, dan Kak Dian Eka Raharjo. Website ini terdiri dari 4 bagian utama yaitu Home, About, Skill, dan Contact. Tampilan layar sudah responsive, menerapkan HTML, CSS, dan JavaScript, serta tidak menggunakan Tailwind/Bootstrap
